# VirtualC OS — Simulated Operating System

VirtualC OS is a program developed entirely in C, designed to run completely through the terminal.
 It is not a real operating system, but **rather simulates the behavior of a shell** such as Bash or PowerShell, providing an interactive environment with custom commands and built-in features.



## Main Features
VirtualC OS provides an interactive prompt that allows users to perform various operations, including:
- Create files
- View file contents
- Delete files
- Display the current date and time
- Open a simple calculator
- Launch a mini-game
- Clear the terminal screen

## Visual Style and Appearance
VirtualC OS adopts a clean and readable style inspired by classic terminal environments.
 The interface features a **colored prompt** that displays only the system name, maintaining a simple and minimalistic appearance.

The colors have been carefully selected to make the user experience clearer and more enjoyable:

- **Cyan** for the system name in the prompt
- **Green** for success messages (completed operations)
- **Yellow** for information and warnings
- **Red** for errors or invalid input
- **White** for standard text and command output

This color scheme allows users to quickly distinguish between different types of messages while preserving a clean and uncluttered design.
The goal is to provide a simple, neat, and minimalistic environment without unnecessary graphical elements.
